# Changelog

All notable changes to the FIGM Code Inspector VS Code Extension will be documented in this file.

## [1.0.0] - 2026-08-05

### Added
- Initial release of FIGM Code Inspector extension.
- Real-time AST static analysis for React, Next.js, Angular, and Vue.
- Red squiggly underlines and Problems Panel integration.
- Rich Hover Provider with WCAG 2.2 AA and ISO 25010 standard citations.
- Quick-Fix Code Action Provider for automated code transformations.
- Status Bar item displaying live Quality Score.
- Output Channel logging for inspection diagnostics.
- Workspace-wide inspection command (`figm.scanWorkspace`).
