## Notes on this reconciliation

- **Correction (Phase 7A, Critical Dissertation Consistency Corrections — RQ4 contradiction and RO1/RO2 labeling defect):** this matrix previously had two defects. First, RO1 and RO2 were both labeled bare "RQ1" with no way to tell whether that was intentional (two objectives jointly supporting one question) or a copy-paste error; both genuinely support the dissertation's canonical RQ1 (`chapter1_introduction.md` §1.4) from two different angles — RO1 the formal meta-model definition, RO2 the AST-normalization mechanism that makes "without losing precision" checkable — so they are now labeled RQ1(a)/RQ1(b) to make that explicit rather than ambiguous. Second, and more seriously, RO5 was labeled "RQ4," directly colliding with this dissertation's actual canonical RQ4 (Developer Usability & Impact) despite asking a completely unrelated question about SaaS multi-tenancy. RO5 has been relabeled as a supporting objective for Chapter 1's Scope statement (§1.6), not a stand-in for RQ4. The canonical RQ4 (usability) remains open per `chapter6_conclusion.md` §6.2 (0/20 participants collected, target revised from an earlier 85 per the supervisor's latest instruction) and correctly has no completed RO row in this matrix — this table only lists objectives with a status to report, and no invented research question was introduced to fill the gap. The dissertation's real RQ1-4 wording is authoritative in `docs/dissertation/chapter1_introduction.md` §1.4 and `chapter6_conclusion.md` §6.2; this matrix's question column should always be read as a paraphrase pointing back to that wording, not as an independent restatement.

- Two "evaluation metric" cells in a prior version of this table (RO3, RO5) asserted **1.00
  Precision/Recall/F1** and **Cronbach's α = 0.892** as if they were completed results. Neither was
  backed by a real computation reachable from the live pipeline: the 100%/100%/100% figure did not
  match any run of `npm run research:evaluate` (the real figure is lower, see the live artifact),
  and the α=0.892 figure was a synthetic formula-verification value, not a real human-study result.
  Both have been corrected above.
- RO2's prior version cited "30 Open-Source SPA Benchmark Repositories" — this dataset never
  existed as real scanned data; see `docs/evidence/research-claim-traceability.md` row 8.
- File paths in a prior version of this table (`src/ast/source-parser.ts`,
  `src/ast/alp-extraction-engine.ts`, `src/ast/rule-execution-engine.ts`) did not match the real
  module locations (`src/parser/`, `src/engine/`) — corrected above. API endpoints `/api/matrix`
  and `/api/remediation` did not exist as separate routes — corrected to the real endpoints.
  Database model names (`ScanReports`, `AIHistory`, plural `Users`/`Projects`) did not match
  `prisma/schema.prisma`'s real singular model names (`ScanReport`, `AiHistory`, `User`,
  `Project`) — corrected above.
