
# Contributing to FIGM Code Inspector

Thank you for contributing to the FIGM Code Inspector project.

---

## Code Style & Testing Requirements

1. **Strict TypeScript**: All pull requests must compile cleanly with `npm run build`.
2. **100% Test Passing**: Run `npm test` to see the current test count and ensure all automated test cases pass before submitting PRs.
3. **Clean Code**: Follow SOLID design principles and preserve documentation comments.
