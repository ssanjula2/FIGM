## 1. PURPOSE OF THE STUDY
You are invited to participate in an empirical research study evaluating the usability, understandability, usefulness, and task completion experience of the **Framework-Independent Guideline Model (FIGM) Code Inspector** when evaluating Single Page Application (SPA) source code across Next.js, React, Angular, and Vue.

## 2. STUDY PROCEDURE & EXPECTED DURATION
If you agree to participate:
1. You will complete a brief background section (programming experience, primary framework).
2. You will use the interactive FIGM Code Inspector to evaluate representative SPA source code fixtures.
3. You will complete 5 structured evaluation tasks (rule identification, understanding diagnostics, locating source lines, understanding recommended fixes, and manual comparison).
4. You will complete the 10 standard System Usability Scale (SUS) questionnaire items.
5. You may optionally provide qualitative feedback on tool improvements.

**Expected Duration**: 15–25 minutes.
