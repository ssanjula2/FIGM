\section{Developer Usability Study}
A target cohort of $N = 20$ student developers at NSBM Green University was planned for a System Usability Scale (SUS) evaluation of FIGM. As of this export, \textbf{0 of 20} real participant responses have been collected (see \texttt{research/CONSENT\_FORM.md} and \texttt{research/raw/real/responses.csv} -- the actual expected-input path read by \texttt{scripts/import-user-study.ts}; a prior version of this chapter cited a non-existent \texttt{data/user-study-responses.json} path, corrected here to the repository's real source-of-truth location) -- no SUS score, patch-acceptance rate, or satisfaction metric is reported here, because none has been measured from real data. A prior version of this chapter reported a completed evaluation with a specific SUS score and satisfaction percentages; those figures were fabricated (invented, with no underlying computation or data source) and have been retracted rather than replaced with different numbers.
