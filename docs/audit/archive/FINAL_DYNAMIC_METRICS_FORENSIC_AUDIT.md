$$\text{benchmarks/testbed/ (147 LOC)} \xrightarrow{\text{UniversalASTMapper.parse()}} \text{ALPs} \xrightarrow{\text{RuleExecutionEngine.analyzeFile()}} \text{Diagnostics}$$
$$\text{Diagnostics} + \text{benchmarks/ground-truth.json} \xrightarrow{\text{EvaluationRunner.runEvaluation()}} \text{TP/FP/FN/TN} \xrightarrow{\text{PrecisionRecallEngine.calculateMetrics()}} \text{Precision, Recall, F1}$$
$$\text{Precision, Recall, F1} \xrightarrow{\text{EvaluationRunner.exportReports()}} \text{docs/evidence/canonical-evaluation.json (Generated Artifact)}$$

- Zero circular dependencies: `EvaluationRunner` never consumes previously generated JSON reports as input.
