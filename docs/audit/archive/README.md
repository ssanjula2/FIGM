# Archived Audit & Verification Reports

This directory holds **historical, point-in-time** audit and verification snapshots that were
previously scattered at the repository root. Each one is dated (see its own "Audit Date" field)
and reflects the state of the codebase as of that date — not the current state.

They were moved here rather than deleted, per the project's evidence-retention practice: nothing
is discarded, but nothing superseded is left where it could be mistaken for a current, authoritative
source. Every file carries an explicit `ARCHIVED — SUPERSEDED` banner at its top.

**For current status, use these instead:**

| Question | Current source |
|---|---|
| What are the current empirical benchmark numbers (TP/FP/FN/Precision/Recall/F1)? | `docs/evidence/canonical-evaluation.json`, regenerated by `npm run research:evaluate` |
| Is a specific research/dissertation claim supported, and by what? | `docs/evidence/research-claim-traceability.md` |
| What is the current rule-by-rule detection architecture (AST vs. legacy)? | `docs/architecture/RULE_ENGINEERING_AUDIT.md`, `docs/architecture/AST_MIGRATION_MAP.md` |
| What is the most recent full forensic audit? | `audit/new.md` (root of the repository) |
| What is the human usability study's real collection status? | `research/analysis/usability-results.json`, surfaced live via `GET /api/research-metrics` |

Do not cite any file in this directory as evidence for a current claim in the dissertation, README,
viva preparation, or any public-facing page.
